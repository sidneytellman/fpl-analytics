About the projection: a simple model, not a prediction. It blends recent form (50%, last five matches played), this season's average (30%) and last season's points per 90 scaled to the minutes the player gets now (20%), then adjusts each fixture for its FPL difficulty rating. It does not know about injuries, rotation or penalties, so use it alongside FPL's own expected points.
